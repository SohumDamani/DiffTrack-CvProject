Experiment 3 — Temporal Chunk Frame Interval

Tested whether the sliding-window chunking strategy materially affects tracking accuracy.

Configurationdelta_avg ↑DifferenceNote
Layer 17, ts=49 — with chunk_frame_interval ★ 47.0 Baseline Paper default
Layer 17, ts=49 — no chunk_frame_interval 46.4 −0.6 Marginal, within noise
Finding 3
Chunking makes virtually no difference

A 0.6-point gap between chunked and unchunked is within small-sample noise. The windowing heuristic cannot fix the method's fundamental lack of temporal memory — each frame is independently matched against frame 0 regardless of the chunking strategy.

Part B

Limitations Analysis

Three failure modes, each tied to explicit paper figures, quantified via controlled ablation experiments.

Limitation 1 — Hard Dependency on Diffusion Noise

Limitation 1
Without noise, correspondence collapses entirely

Every metric is zero across all four test videos. The correspondence signal is emergent from the denoising process itself — remove it and there is nothing to track. At ts=1, the pipeline feeds clean VAE latents to a transformer conditioned at t=980 (near-maximum noise). The model expects heavily-noisy latents at t=980; receiving clean latents creates a distribution mismatch that destroys all feature correspondences.

Limitation 2
Performance varies by 16+ points across layers — with no selection criterion

Layer 8 matches objects at the same spatial position due to RoPE positional embeddings dominating (paper Figure 6). Layer 29 shows diffuse, scattered attention (paper Figure A.18). Fine-grained spatial precision favors mid-network layers, but the paper provides no empirical guide for layer selection on a new domain or architecture.

Limitation 3 — No Temporal Memory: Accuracy-vs-Threshold Analysis

Accuracy drops sharply at tight thresholds — revealing the method's lack of any motion model, velocity estimate, or trajectory history.

Limitation 3
Precision collapses at tight thresholds — no motion continuity

Only 7% of predictions land within 1 pixel, versus 81% within 16 pixels — a 12× accuracy spread across thresholds. The method independently matches each frame against frame 0 with no motion model or velocity estimate. Without trajectory history, drift compounds over long sequences — the method is a one-shot matcher, not a tracker in the classical sense.

Part C

CAG Motion Guidance Demo

Cross-Frame Attention Guidance (CAG) repurposes the same correspondence mechanism for zero-shot motion transfer — no fine-tuning, no labels, same frozen model.

PAG Strength = 0 — Baseline Generation

No cross-frame attention guidance applied. Produces plausible but uncontrolled motion. The video DiT generates frames independently without any external motion prior. No trajectory is injected.


Open pag_scale=0 videos in Drive ↗
PAG Strength = 1 — With CAG Applied

Cross-frame attention keys/values from a reference video replace those in the target generation during denoising. This injects the reference video's motion pattern without any finetuning or labels. Motion transfer is visible and steered by source trajectories.

Key Insight
Same attention maps — two applications

The same cross-frame query-key attention that enables zero-shot point tracking also enables zero-shot motion transfer. CAG demonstrates the generality of the correspondence mechanism: it is not a tracking-specific artifact but a fundamental property of how video DiTs organize temporal information.

Root Causes Identified

Root Cause 1 — Noise Dependency
Correspondence is emergent, not designed

Tracking works because denoising at ts=30–49 creates temporally-coherent attention maps as a side effect. Too little noise (ts≤5) collapses the mechanism; the model was never explicitly trained to track anything.

Root Cause 2 — No Temporal Memory
Frame-0 independent matching

Every frame is matched against frame 0 independently. There is no velocity estimate, motion prior, or trajectory history. Precision degrades by 12× from 1px to 16px threshold — the model accumulates no context about where a point has been.

New Findings Beyond Original Paper

New Findings
What we add to the paper's analysis

Plateau framing: ts=30–49 form an effective operating plateau — the 0.8-point difference between ts=30 and ts=49 is within small-sample noise, not a meaningful peak.

Noise floor: There is a hard noise floor at ts≤5 below which the tracker fails as completely as at ts=1. The failure cliff is sharp — ts=10 gives 13.1, ts=5 gives 0.8.

Threshold-accuracy spread: The 12× accuracy gap between delta_1 and delta_16 is not discussed in the paper; it reveals the method's fundamental precision ceiling for real-world applications requiring sub-pixel accuracy.
